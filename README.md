## Gebregziabihier Nigusie Birhane

I worked on RAG for text-to-SQL report generation and on fusion models for archiving African heritage sounds. I fine-tuned pretrained models for low-resource languages like Amharic and built a lightweight mobile model for pneumonia detection from chest X-rays. I'm open to research and project collaborations in language technologies, computer vision, and software development.

## Projects

### Heritage in Code: AI Fusion Engine
*Wits Innovation Center, Nov 2025 – Jun 2026*

Archival pipeline and audio fusion engine for the creative reuse of African heritage sounds, using Chromaprint, Demucs and MusicGen. [heritageincode.com](https://www.heritageincode.com/)

### Rubani: Financial Report Generation Agent
*AI Engineer, 2026 – Present*

RAG pipeline for schema ranking and natural-language-to-SQL, with a fine-tuned Qwen 3B model that turns retrieved records into structured financial reports.
