## Areas of Work

### Language Technologies & Low-Resource NLP

My research originated from a practical challenge: improving the accessibility of Amharic educational text. For my MSc thesis, I investigated lexical complexity detection and simplification using machine learning, including the fine-tuning of pretrained language models such as BERT and RoBERTa.

I continued this research through work on annotation methodology, classification approaches, and subsequent studies on Amharic language understanding.

My more recent NLP research examines the use of large language models for analyzing sentiment polarity in Amharic-language discourse on climate change.

### Medical AI & Resource-Constrained Deep Learning

I developed a contour-guided lung segmentation and X-ray validation approach for pneumonia detection, together with a lightweight deep learning model designed for mobile inference.

This work addresses a significant deployment challenge: enabling the practical use of medical AI in settings with limited computational resources.

The research was presented at MICCAI 2025 and published in the associated workshop proceedings in 2026.

### Generative AI, RAG & Intelligent Applications

My engineering work includes building systems that connect large language models with external data, specialized knowledge, and real-world applications.

At Rubani, I am developing a financial report generation agent that combines vector-based database schema ranking, natural-language-to-SQL generation, and a fine-tuned Qwen 3B model to convert retrieved financial records into structured reports.

At Wits Innovation Center, I contributed to Heritage in Code, an AI-driven project examining how African musical heritage can be archived, understood, and creatively reused through audio processing and generative models.

## Selected Engineering Projects

### 01. Rubani – Financial Report Generation Agent
**AI Engineer | March 2026 – Present**

Currently developing an AI-powered financial intelligence system that translates natural-language questions into database queries and generates structured reports from retrieved financial information.

Key engineering contributions:

- Developed a RAG pipeline for vector-based database schema ranking to identify the tables and fields relevant to user queries.
- Implemented natural-language-to-SQL workflows for retrieving relevant records from relational databases.
- Fine-tuned a Qwen 3B model using RAG-based supervision for financial report synthesis.
- Integrated retrieved tabular data into structured report generation workflows.

**Technical focus:** Python, RAG, Qwen, LLM Fine-tuning, SQL, Vector Retrieval.

### 02. Heritage in Code – AI Fusion Engine
**AI Engineer | Wits Innovation Center, South Africa | November 2025 – June 2026**

Contributed to an AI-driven initiative focused on preserving African musical heritage while enabling new forms of creative reuse.

Key contributions:

- Developed an archival pipeline for African heritage sounds and their associated cultural context.
- Built an audio fusion engine using Chromaprint for audio similarity tracking.
- Applied Demucs for source separation and pitch analysis.
- Used MusicGen as a generative baseline to evaluate the outputs of the fusion engine.

**Technical focus:** Python, TypeScript, Chromaprint, Demucs, MusicGen, Hugging Face.

**Project:** [heritageincode.com](https://www.heritageincode.com/)

### 03. Mobile Pneumonia Detection
**Research Project | MICCAI 2025 Workshop**

Developed a contour-guided segmentation and X-ray validation approach for pneumonia detection, together with a lightweight deep learning model targeting real-time mobile inference.

The work focused on validating chest X-ray images and improving the practicality of AI-assisted pneumonia detection in resource-constrained environments.
